## 2025-05-15 - Canvas Overdraw and Layout Thrashing in Single-File Landing Pages
**Learning:** High-frequency canvas animations drawing radial lights across the screen suffer from massive overdraw when `fillRect(0, 0, w, h)` is called repeatedly for localized light sources. Restricting the canvas drawing path using a localized bounding box matching the gradient radius (e.g., `fillRect(x - r, y - r, r * 2, r * 2)`) dramatically reduces GPU/CPU paint times. Furthermore, query operations like `offsetTop` inside high-frequency scroll handlers cause synchronous reflow (layout thrashing) when combined with dynamic layout changes.
**Action:** Always pre-calculate section scroll offsets during load/resize events and restrict drawing scopes with localized canvas fills instead of screen-wide fills.
