## 2025-05-18 - Scroll Listener Layout Thrashing & Redundant DOM Invalidation
**Learning:** In single-page landing pages with fixed headers and scroll spy listeners, reading DOM layout properties like `element.offsetTop` inside the scroll event callback forces synchronous layout recalculation on every scroll tick. Furthermore, mutating style properties (`element.style.color`, `element.style.background`) unconditionally on every scroll tick invalidates styles continuously even when visual state hasn't changed.
**Action:** Pre-compute and cache section offsets on load and window resize. Guard DOM style modifications behind state equality checks (`currentActiveNavId` and boolean thresholds like `isScrolledPast50`) to eliminate unnecessary layout recalculations and style recalculations during scrolling.
