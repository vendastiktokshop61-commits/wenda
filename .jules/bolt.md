## 2025-10-07 - Canvas Ambient Radial Gradient Bounds & Hex Formatting Optimization
**Learning:** Calling `ctx.fillRect(0, 0, canvas.width, canvas.height)` for multiple full-screen radial light gradients incurs heavy fill-rate rasterization overhead (~4M pixels/frame at 1280x800). Localizing `fillRect` bounds to each radial light's bounding square `(x - r, y - r, 2r, 2r)` dramatically reduces rasterization area and CPU/GPU fill time. Additionally, string conversion (`toString(16).padStart(2, '0')`) inside RAF loops causes high GC allocation churn; a pre-calculated 256-entry `HEX_TABLE` lookup array completely eliminates string allocation overhead.
**Action:** When working with canvas radial gradients or color string creation in high-frequency RAF loops, always bound fillRect to the shape's bounding box and pre-calculate hex lookup strings.
