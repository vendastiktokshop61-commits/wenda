## 2026-08-14 - Canvas Overdraw & Scroll Event Reflow Optimization
**Learning:** Localizing radial gradient `fillRect` calls to bounding boxes (`l.x - l.r, l.y - l.r, l.r * 2, l.r * 2`) prevents full canvas overdraw on each frame. Pre-calculating static trigonometric vectors (`cosAngle`, `sinAngle`) and RGB string templates eliminates string parsing and math overhead in 60 FPS animation loops. Furthermore, caching DOM offsets (`offsetTop`) on load/resize eliminates forced synchronous layout reflows during scroll handling, and state-guarding style writes prevents style invalidation thrashing.
**Action:** When working with canvas animations or window scroll listeners, always bound gradient fills, pre-calculate constant math/color strings outside the frame loop, cache element layout geometry, and guard DOM style mutations with state checks.
