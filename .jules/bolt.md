## 2025-10-26 - Single-Page HTML Canvas & Scroll Event Optimizations
**Learning:** In vanilla JS canvas animations running at 60 FPS, calling `Math.round(val * 255).toString(16).padStart(2, '0')` and `ctx.save()/ctx.restore()` in render loops introduces substantial garbage collection and state overhead (~2.7x slower frame JS computation). Furthermore, querying `section.offsetTop` inside scroll listeners causes layout thrashing on every scroll tick.
**Action:** Pre-calculate a 256-entry `HEX_TABLE` lookup array for alpha hex values, pre-calculate trigonometric vectors (`Math.cos`/`Math.sin`), bound radial gradient fills to light radii (`[x-r, y-r, 2r, 2r]`), use explicit context property resets instead of `save()/restore()`, and cache DOM layout offsets on resize with state-guarded style mutations.
