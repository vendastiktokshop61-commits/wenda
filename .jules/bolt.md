## 2025-05-15 - Canvas and Scroll Optimization
**Learning:** Localizing fillRect to a localized bounding box for radial gradients significantly reduces overdraw on large ambient light layers. Pre-calculating trig values (cos/sin of streak angles) and color components avoids redundant math and string parsing inside high-frequency animation loops. Pre-calculating and caching section offsets on load and window resize events avoids layout thrashing / forced synchronous layout reads inside scroll handlers.
**Action:** Always localize gradient fills to the actual rendering boundary of radial gradients instead of clearing/drawing on the full canvas size. Precompute any static trig and color patterns during initialization, and keep DOM reads out of continuous event loops (like scroll).
