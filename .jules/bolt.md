## 2025-10-30 - Canvas Animation and Scroll Handler Optimization in index.html
**Learning:** In canvas rendering loops, repeatedly calling `.toString(16).padStart(2, '0')` for alpha conversion and `Math.cos()`/`Math.sin()` on fixed streak angles causes noticeable JS execution overhead. Pre-calculating a 256-entry `HEX_TABLE` lookup array and trigonometric constants (`cosA`, `sinA`, `halfLen`) yields a ~1.81x draw loop speedup. Additionally, bounding radial gradient `fillRect` calls to light radii `(2*r x 2*r)` instead of full viewport canvas bounds `(W x H)`, replacing `ctx.save()`/`ctx.restore()` with explicit property resets (`ctx.shadowBlur = 0`), and state-guarding DOM mutations in scroll handlers eliminates layout thrashing during scroll.
**Action:** Always pre-calculate lookup tables and static trigonometric vectors for canvas rendering loops, bound fillRect operations, and state-guard scroll event handlers to avoid unnecessary layout thrashing.
