## 2026-05-15 - Canvas Overdraw and Forced Reflow Resolution
**Learning:** High frequency background animations drawing full-screen radial gradients (`ctx.createRadialGradient`) consume considerable CPU time and cause unnecessary overdraw. Localizing the `ctx.fillRect` to the exact gradient bounding box reduces pixel fills to just the gradient surface area. Furthermore, reading `element.offsetTop` inside scroll event listeners triggers synchronous layout recalculations (forced layout reflow).
**Action:** Always pre-calculate trig values outside requestAnimationFrame loops, avoid repetitive hex-to-rgb string parsing, restrict radial fills to the bounding box of the gradient, and cache DOM offset parameters on window load/resize while state-guarding style mutations to avoid layout thrashing.
