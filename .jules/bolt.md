## 2025-05-15 - Optimizing high-frequency canvas loops and scroll event handling in index.html
**Learning:** Localizing `fillRect` coordinates to a bounding box rather than filling the entire canvas reduces ambient light overdraw on large screens. Pre-calculating static properties (such as trigonometry and length parameters) avoids garbage collection pauses and redundant calculation cycles in animation frames. Removing `ctx.save()` and `ctx.restore()` in favor of manual property resets (like `ctx.shadowBlur = 0`) prevents costly canvas state management context switches. For scroll handling, caching DOM offsets prevents forced synchronous layouts (layout thrashing) while state-guarding style writes completely removes redundant style updates.
**Action:** Always check high-frequency events and requestAnimationFrame loops for layout/reflow triggers (e.g. s.offsetTop), context-switching stack actions (ctx.save/restore), and full-screen fills (fillRect) and optimize them using state caching, pre-calculation, and localized rendering.
